# InfluxDB Setup for JMeter Performance Testing

## 1. Objective
Integrate Apache JMeter with InfluxDB to store and analyze API performance testing metrics.

## 2. Tools Used
- Apache JMeter 5.6.3
- InfluxDB OSS 1.13.2
- Windows PowerShell
- InfluxDB Backend Listener

## 3. Installation
Downloaded the Windows 64-bit InfluxDB ZIP package from the official InfluxData website and extracted it to C:\InfluxDB.

Started the InfluxDB server:
```powershell
& "C:\InfluxDB\influxd.exe"
```

Verified that the server responded successfully at http://localhost:8086/ping with HTTP status 204.

## 4. Database Creation
Created a database for JMeter metrics:
```powershell
& "C:\InfluxDB\influx.exe" -execute "CREATE DATABASE JMeterPerformanceDB"
```

Verified the database:
```powershell
& "C:\InfluxDB\influx.exe" -execute "SHOW DATABASES"
```

## 5. JMeter Backend Listener Configuration
Selected the InfluxDB Backend Listener implementation:

`org.apache.jmeter.visualizers.backend.influxdb.InfluxdbBackendListenerClient`

Configured:
- influxdbMetricsSender: org.apache.jmeter.visualizers.backend.influxdb.HttpMetricsSender
- influxdbUrl: http://localhost:8086/write?db=JMeterPerformanceDB
- application: JMeterAPITest
- measurement: jmeter
- summaryOnly: true
- samplersRegex: .*
- percentiles: 90;95;99
- testTitle: API Load Test - 5 Users

## 6. Verification
Executed the JMeter API test and checked the measurements:
```powershell
& "C:\InfluxDB\influx.exe" -database JMeterPerformanceDB -execute "SHOW MEASUREMENTS"
```

InfluxDB returned the measurements `events` and `jmeter`.

Queried stored results:
```powershell
& "C:\InfluxDB\influx.exe" -database JMeterPerformanceDB -execute "SELECT * FROM jmeter LIMIT 5"
```

The results confirmed that InfluxDB received performance data, including response times, sample counts and error counts.

## 7. Troubleshooting
The Windows PowerShell version did not recognize the `-StatusCodeVariable` parameter for `Invoke-RestMethod`.

Used this compatible command instead:
```powershell
(Invoke-WebRequest -Uri "http://localhost:8086/ping" -UseBasicParsing).StatusCode
```

Result: HTTP 204, confirming that the InfluxDB server was responding.

## 8. Interview Preparation

**Q: Why use InfluxDB with JMeter?**

InfluxDB stores time-series performance metrics generated by JMeter, allowing us to analyze trends and visualize results over time.

**Q: What is the Backend Listener?**

The Backend Listener is a JMeter component that sends performance metrics to external monitoring systems during test execution.

**Q: How did you verify the integration?**

I queried the InfluxDB database using InfluxQL and confirmed that the `jmeter` measurement contained actual performance test records.
